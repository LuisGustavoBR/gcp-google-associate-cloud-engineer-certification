# Cloud Identity and Google Cloud Directory Sync

> **Level:** Intermediate · **Topic:** [Identity and security](../README.md) · **Cited in:** 3 practice-exam questions

## What it is

Cloud Identity manages users, groups, and MFA. **GCDS** synchronizes users from LDAP or AD to Cloud Identity (one direction only).

## Trigger

"users in LDAP, by organizational unit, with additions and removals reflected" ([E3Q5](../../99-practice-exams/exam-3.md#q5)). "Personal accounts already created with the corporate email": transfer invitation ([E2Q10](../../99-practice-exams/exam-2.md#q10)). Scaling access management: **groups** and MFA ([E3Q11](../../99-practice-exams/exam-3.md#q11)).
