# Official resources

## Google (authoritative)

- [Associate Cloud Engineer exam guide](https://cloud.google.com/learn/certification/guides/cloud-engineer): sections, weights and topics. Check it before booking, it changes.
- [Google Cloud documentation](https://cloud.google.com/docs): the final authority for product behavior and names.
- [gcloud CLI reference](https://cloud.google.com/sdk/gcloud/reference): every command and flag.
- [Google Skills learning path 69](https://partner.skills.google/paths/69): the official course list for the certification. **Not summarized here:** the page requires a login and could not be read automatically, so the course list is missing from this repo. Open it in a browser to see the course list.

Per-product documentation links are on each product page, under "Official documentation". They were collected from the reference links of the practice-exam explanations and checked to return HTTP 200 on 2026-10-24.
