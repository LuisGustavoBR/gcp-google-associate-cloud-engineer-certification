# Cloud NAT

> **Level:** Intermediate · **Topic:** [Networking](../README.md) · **Cited in:** 2 practice-exam questions

## What it is

Outbound internet access for VMs and nodes without an external IP. Accepts manual static IPs.

## Trigger

"download patches without an external IP" ([E6Q25](../../99-practice-exams/exam-6.md#q25)). "External vendor that only allows known IPs" ([E4Q25](../../99-practice-exams/exam-4.md#q25)).
