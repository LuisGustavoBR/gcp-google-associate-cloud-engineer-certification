# VPC Network Peering and Shared VPC

> **Level:** Intermediate · **Topic:** [Networking](../README.md) · **Cited in:** 2 practice-exam questions

## What it is

Peering connects two VPCs simply and cheaply, and the IP ranges cannot overlap. In Shared VPC, a host project provides the network and service projects use it.

## Trigger

"two projects, simple and cheap communication" points to Peering ([E1Q47](../../99-practice-exams/exam-1.md#q47)). "Landing zone for several production projects" points to Shared VPC ([E4Q27](../../99-practice-exams/exam-4.md#q27)).
