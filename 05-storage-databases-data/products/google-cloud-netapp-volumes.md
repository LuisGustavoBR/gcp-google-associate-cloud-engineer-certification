# Google Cloud NetApp Volumes

> **Level:** Advanced · **Topic:** [Storage, databases and data](../README.md) · **Cited in:** 1 practice-exam question

## What it is

Fully managed enterprise file storage (NAS). It supports SMB and NFS, integrates with Active Directory, and offers snapshots, replication, backup, and access control.

## Trigger
