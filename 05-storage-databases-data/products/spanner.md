# Spanner

> **Level:** Intermediate · **Topic:** [Storage, databases and data](../README.md) · **Cited in:** 7 practice-exam questions

## What it is

Relational database with strong consistency, horizontal scaling, and a multi-region option.

## Trigger

"global", "strong consistency", and "horizontal scaling" ([E1Q28](../../99-practice-exams/exam-1.md#q28), [E2Q5](../../99-practice-exams/exam-2.md#q5), [E4Q16](../../99-practice-exams/exam-4.md#q16), [E4Q35](../../99-practice-exams/exam-4.md#q35), [E6Q19](../../99-practice-exams/exam-6.md#q19)).

## Watch out

Enable the Spanner API before creating the first instance ([E5Q1](../../99-practice-exams/exam-5.md#q1)). High-priority CPU alert at 65%: add nodes ([E2Q35](../../99-practice-exams/exam-2.md#q35)).
