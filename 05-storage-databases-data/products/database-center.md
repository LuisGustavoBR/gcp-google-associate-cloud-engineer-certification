# Database Center

> **Level:** Advanced · **Topic:** [Storage, databases and data](../README.md) · **Cited in:** 1 practice-exam question

## What it is

Central dashboard showing the health of an entire database fleet (Bigtable, Cloud SQL, Memorystore, Spanner). It highlights configurations that can cause downtime, missing data protection, or security issues.

## Trigger

"a single pane of glass for the health of all databases".

## Watch out

Cloud Asset Inventory only lists resources; it does not assess health.
