# Gemini Cloud Assist

> **Level:** Intermediate · **Topic:** [IaC, platform and AI tooling](../README.md) · **Cited in:** 3 practice-exam questions

## What it is

AI assistant for operations. *Investigations* perform root cause analysis in distributed environments. There is also "Explain this log entry" in Logs Explorer.

## Trigger

"502 errors across a chain of services", "quickly understand an unfamiliar log".

## Watch out

Enabling it at folder scope is done on the **Admin for Gemini** page of the console. There is no CLI command for this.
