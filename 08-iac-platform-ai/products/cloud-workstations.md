# Cloud Workstations

> **Level:** Intermediate · **Topic:** [IaC, platform and AI tooling](../README.md) · **Cited in:** 4 practice-exam questions

## What it is

Managed development environments, accessible through the browser. A shared configuration defines the approved image, persistent home, and idle timeout.

## Trigger

"standardized environment for each engineer", "shut down automatically when idle".

## Watch out

Configuration changes only take effect after the workstation is restarted.
