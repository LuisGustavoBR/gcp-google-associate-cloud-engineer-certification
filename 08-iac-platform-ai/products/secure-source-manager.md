# Secure Source Manager

> **Level:** Intermediate · **Topic:** [IaC, platform and AI tooling](../README.md) · **Cited in:** 1 practice-exam question

## What it is

Managed **Git** repositories, with branches, pull requests, approvals, and audit history.

## Trigger

"peer review before deploying the infrastructure".

## Watch out

A Cloud Storage bucket stores files, but offers no code review or pull requests.
