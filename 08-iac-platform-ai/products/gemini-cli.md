# Gemini CLI

> **Level:** Intermediate · **Topic:** [IaC, platform and AI tooling](../README.md) · **Cited in:** 2 practice-exam questions

## What it is

AI agent that runs in the terminal and works inside a local repository, for example generating code and tests.

## Watch out

The generated code needs review, validation, and `terraform plan` before deployment. It does not enable Cloud Assist.
