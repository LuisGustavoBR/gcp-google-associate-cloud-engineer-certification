# Cloud TPU and GPU

> **Level:** Intermediate · **Topic:** [Compute and containers](../README.md) · **Cited in:** 3 practice-exam questions

## What it is

TPU is hardware for matrix operations in ML. NVIDIA GPU serves code that uses **CUDA**.

## Trigger

"JAX / LLM training" points to TPU ([E1Q48](../../99-practice-exams/exam-1.md#q48)). "CUDA extensions" points to GPU ([E1Q13](../../99-practice-exams/exam-1.md#q13), [E5Q22](../../99-practice-exams/exam-5.md#q22)).
